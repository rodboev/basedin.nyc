Methodology

Both repos use a cherry-pick workflow: the maintainer picks commits and closes the PR without GitHub's merge button, so mergedAt is always null. "Shipped" is determined from maintainer comments referencing a release version.

PRs classified as "withdrawn" had no maintainer interaction beyond automated bot reviews (Greptile). "Lost" means a competing PR addressing the same issue was accepted instead (superseded or consolidated by another contributor's PR).

"Credited" in the leaderboard counts closed + merged PRs. For rodboev, this is refined to shipped only (comment-based classification). Other contributors use raw closed count as a proxy since comment scanning at scale would hit API rate limits.
