Methodology

Shipped means maintainer-accepted work: a direct merge, timeline evidence such as a release PR or cherry-pick reference, or an indirect landing credited back to the original PR. GitHub's mergedAt flag alone is not sufficient because some repos land contributor work outside the merge button.

Withdrawn, superseded, and lost separate author pullbacks, maintainer replacements, and competing outcomes. The PR table is sorted newest-first using close time for closed PRs and creation time for open PRs.

Community leaderboards rank third-party contributors only. Repo owners, maintainers, integration bots, and other automated accounts are excluded. Each board shows the top 50 contributors. For the top 20 ranked contributors, Credited uses the same lifetime shipped evidence rules as this page across all closed PRs returned by GitHub (up to 500 per author). Lower rows use a faster closed-PR proxy. Rate (7d) is PRs opened in the rolling last 7 days divided by 7 (a recent per-day opening rate, not merge velocity).
