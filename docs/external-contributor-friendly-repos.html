AI Repos That Actually Merge External PRs

Verified by checking GitHub org membership for every merged PR author. Most "active" repos that look contributor-friendly are 90%+ internal commits.

Our earlier repo selection (skillspector, gym, agent-native) produced false signals because we weren't distinguishing internal from external contributor merges. Internal contributors merge same-day everywhere; external merge speed is the real signal.

Sections

Methodology

For each repo, I pulled the 15 most recently merged PRs via gh pr list, then verified each author's org membership with gh api orgs/{org}/members/{user}. Repos where external authors routinely merge in 0-3 days are Tier 1. Repos where external merges happen but at lower volume are Tier 2.

Checked ~25 AI/AI-tooling repos across GitHub Trending (monthly), OSSInsight AI rankings, and Trendshift.

Discovery Sources

GitHub built-in

  • GitHub Trending (daily / weekly / monthly)
  • GitHub Explore (personalized recommendations)
  • GitHub Topics (category browsing)

No built-in "hot" or "popular" ranking beyond these three.

Third-party rankings

  • OSSInsight — real-time AI repo rankings from 10B+ GitHub events, hourly updates
  • Trendshift — catches repos as they rise, not after they peak
  • GitHub Ranking (EvanLi) — auto-updated Top 100 by stars per language
  • RepoInsider — weekly newsletter: 5 breakout repos every Monday, ranked by velocity not stars
